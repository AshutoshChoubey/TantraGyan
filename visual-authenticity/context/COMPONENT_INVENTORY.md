# Component Inventory — TantraGyan

## 1. UI Components & Modules
- **Book Stage (`.book-stage`, `.book-container`):** Realistic 3D perspective viewport holding the hardcover book with double-sided leaf simulation.
- **Top Bar Controls (`.reader-header`, `.nav-bar`):** Table of contents drawer, font-size adjuster, fullscreen toggle, sound effects toggle, night-mode switcher.
- **Table of Contents Panel (`.toc-drawer`, `.toc-list`):** Hierarchical navigation tree spanning all chapters and verses.
- **Audio Synthesizer Engine (`sound.js`):** Web Audio API acoustic paper rustle and page-turning sounds.
- **Search & Filter Modal (`.search-modal`):** Real-time text search highlighting Sanskrit terms, planetary aspects, and chapter indices.
- **Vedic Chart Renderers (`.kundali-chart`):** North Indian diamond Kundali birth charts and South Indian square charts.
