# Project Overview — TantraGyan

## 1. Identity & Mission
**TantraGyan** is a comprehensive Vedic astrology, occult science, and sacred text platform dedicated to authentic scriptural research, Brihat Parashara Hora Shastra, Bhrigu Nandi Nadi, and Tantra Sadhana.

The platform provides interactive 3D digital book readers, high-resolution printable PDF editions, astrological chart rendering, and bilingual (Hindi/English) spiritual education.
